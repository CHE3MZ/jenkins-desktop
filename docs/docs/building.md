# Building from Source

## Prerequisites

- Go (see `go.mod` for the version)
- [Bun](https://bun.sh)
- [Wails v2](https://wails.io) (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)

## Packaging the app

```sh
./scripts/build-macos.sh
```

This checks the tools, applies the Xcode link workaround below, runs `wails build`, and produces `build/bin/Jenkins Desktop.app`. Extra arguments are passed through to `wails build` (e.g. `./scripts/build-macos.sh -clean`).

### Xcode link note

Newer Xcode toolchains fail to link the Wails webview (`undefined _OBJC_CLASS_$_UTType`). The script handles this with:

```sh
export CGO_LDFLAGS="$CGO_LDFLAGS -framework UniformTypeIdentifiers"
```

If you invoke `wails build` directly, export that first.

## Live development

```sh
wails dev
```

This runs the Vite dev server with hot reload. Note that in dev mode the app inherits your terminal's `PATH`, while a Finder-launched `.app` gets the minimal system `PATH` — the app compensates by adding the Homebrew locations itself (see [How It Works](how-it-works.md#finding-jenkins)), but keep the difference in mind when debugging startup issues.

## Debugging the splash screen

`app.go` has a `debugSplash` constant. While `true`, the app stays on the splash screen forever without starting Jenkins — useful for iterating on the UI. Set it to `false` for normal behavior.

## Project layout

```text
app.go            Jenkins process manager (spawn, probe, logs, shutdown)
main.go           Wails entrypoint and window options
proc_unix.go      process-group helpers (macOS/Linux)
proc_windows.go   process helpers (Windows)
frontend/src/     Vue + TypeScript UI (splash screen)
frontend/wailsjs/ generated Go bindings (regenerated by wails build)
scripts/          build-macos.sh and icon helpers
build/darwin/     macOS bundle files (Info.plist, icon.icns)
reference/        upstream Jenkins repo, used for UI reference (git-ignored)
```
